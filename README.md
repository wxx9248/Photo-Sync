# Photo Sync

Two applications that move photos and videos off Android phones onto a Linux desktop over the
home network, then free space on the phone once the desktop can prove it holds the files.

* `docs/BOOTSTRAP.md` is where to start, for a person or an agent.
* `docs/SPEC.md` describes what the system does.
* `docs/STACK.md` describes what it is built from.
* `docs/VERIFICATION.md` describes how correctness is decided.
* `docs/CONVENTIONS.md` describes how code and documents are written.
* `docs/ROADMAP.md` describes the order the work happens in.
* `docs/DEVELOPMENT.md` describes where the work runs and how to set a machine up.
* `AGENTS.md` is the operating file for implementation work.
